# ⚡ UPShiksha PDF Tools

Free Online PDF Utilities – Clean Pink & White UI

## Features (Complete Version)
- 📚 Merge PDF
- 🗜️ Compress PDF (Ghostscript – Under 100KB / 200KB / 500KB / 1MB / High Quality)
- ✂️ Split PDF
- 🖼️ Image to PDF
- 🔄 Rotate PDF
- 🔐 Password Protect
- 📑 Organize / Reorder pages

## UI
- UPShiksha style Pink & White theme
- Fully responsive (mobile friendly)
- Card based tool selection
- Hindi + English mixed

## Deploy on Render (Free)

1. Push this repo to GitHub
2. Go to https://render.com → New → Web Service
3. Connect the repository
4. Settings:
   - **Runtime**: Docker
   - **Instance Type**: Free
5. Click Deploy

You will get a link like: `https://your-app.onrender.com`

## Local Run

```bash
# Install Ghostscript first
# Ubuntu/Debian: sudo apt install ghostscript
# Mac: brew install ghostscript

pip install -r requirements.txt
python app.py
```
